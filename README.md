<h2>📌 About the Project</h2>

<p>
<b>Job Search Engine</b> is a frontend web project designed around
a job-search experience. It contains multiple pages covering
job discovery, user accounts, login, and other sections of the website.
</p>

<p>
The project was developed to practice multi-page website development,
frontend design, HTML structure, CSS styling, and JavaScript.
</p>
